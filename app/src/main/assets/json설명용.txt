

rewards : 아이템 id는 item_list.json 참고
statRewards: statType은 스탯 타입 4가지와 경험치 1가지 해서 총 5가지 중에서 보상 선택 여러 종류의 스텟 보상을 줄 수 있다.
설명 중간에 [이미지이름] 을넣으면 이미지가 나오는 이벤트를 만들 수 있다.
!!!!! 그리고 반드시 이미지 앞뒤로 \n을 넣어서 줄바꿈 시켜줘야한다. !!!

type : 타입은 소모품 consumables, 특별한 아이템 artifact, 무기 weapon,갑옷 armor 

[몬스터 기술] monster_list.json의 patterns
평타 대신 쓰는 공격이다. 독·회복 같은 특수 효과는 없다.
  name : 기술 이름 (전투 기록에 「이름」으로 나온다)
  power : 한 번 때릴 때 공격력의 몇 % (150이면 1.5배)
  hits : 몇 번 때리는지 (2 이상이면 "N연타")
  charge : true면 한 턴 기운을 모았다가 다음 턴에 쓴다. 모으는 턴엔 공격하지 않고, 다음 턴에 방어하면 피해 절반
일반 몬스터는 기술 1개: 평타 2 : 기술 1
보스는 기술 2개: 체력이 절반보다 많으면 평타·첫 기술 1/2씩, 절반 이하가 되면 평타·첫 기술·두 번째 기술 1/3씩

[던전] dungeon_list.json
  id : 던전 id. 클리어 기록에 남으므로 시나리오가 달라도 겹치면 안 된다
  name, description, imgId : 던전 고르기 화면에 나오는 이름·설명·그림 (그림이 없으면 dungeon_entrance)
  clearFloor : 이 층을 넘기면 클리어
  requires : 먼저 클리어해야 열리는 던전 id (null이면 처음부터 열림)
  aiEvents : 신들의 이벤트(AI) 수. 1, 21, 41, 61층 순서로 나오고 clearFloor 이상은 만들지 않는다
  statMultiplier : 몬스터 체력·공격력 배수
  rewardMultiplier : 이벤트 보상을 몇 번 받는지
  clearGems : 클리어 보상 젬 (기본 정산에 더한다)
  bossEventId : 마지막 층(clearFloor)에 반드시 나오는 이벤트. 도망 선택지는 retry:true로 둔다
  clearText : 마지막 층을 넘었을 때 나오는 글
모든 던전은 같은 층별 이벤트·몬스터를 쓴다. 이벤트에 "dungeons": ["dungeon_2"] 처럼 적으면 그 던전에서만 나온다.
다른 테마의 던전은 assets/scenarios/<시나리오>/ 폴더에 이 파일과 event·monster·item 목록을 함께 넣는다.

[시련의 신] event_list.json의 trialStat (전투 이벤트)
  trialStat : 힘 | 민첩 | 체력 | 지혜. 넣으면 그 스탯을 시험하는 결투가 된다 (AI의 마법·도적·힘·단련의 신이 만든다)
  - 싸울 때 플레이어의 그 스탯 3당 적의 체력·공격력 +1% (최대 2배, 던전 배수 위에 곱한다)
  - action이 battle인 선택지로 이기면 그 스탯이 (스탯의 1/4 + 2)만큼 오른다. minFloor 층의 상한까지, 던전 보상 배수만큼 반복
  - 이벤트 화면에 지금 스탯으로 정해지는 세기와 보상이 한 줄로 나온다

[아이템 등급] item_list.json의 grade
  grade : COMMON(일반·회색) | UNCOMMON(고급·초록) | RARE(희귀·파랑) | EPIC(영웅·보라) | LEGENDARY(전설·금색). 없으면 일반
  - 보이는 것만 다르다: 가방·장비 칸, 아이템 창, 상점, 도감에 등급 색 테두리가 그려지고 이름이 등급 색이 된다. 스탯·가격은 그대로
  - 처음 나오는 층으로 정했다: 1~10 일반, 11~20 고급, 21~35 희귀, 36~50 영웅, 51층부터 영웅(66층 이후 장비는 전설). 보스가 주는 장비는 한 등급 위
  - 소모품은 회복량으로: 100 미만 일반, 100~ 고급, 150~ 희귀, 300~ 영웅, 550~ 전설
  - imgId의 그림이 없으면 종류 아이콘(ic_weapon·ic_armor·ic_artifact, 소모품은 item_img_34)이 대신 나온다

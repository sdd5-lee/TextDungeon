# Play Console 입력 답안 (2026-10-30)

출시 준비 11번을 Play Console 화면 순서대로 옮긴 것이다. 왼쪽은 Console이 묻는 것, 오른쪽은 넣을 답이다. Console 버전에 따라 문구는 조금 다를 수 있다.

## 0. 먼저 정할 것 (답을 알려 주면 방침과 이 문서를 맞춰 고친다)

| 질문 | 고를 것 | 메모 |
| --- | --- | --- |
| Q1. 타겟 연령 그룹 | **A. 16~17세 + 18세 이상** (권장) / B. 13~15세 + 16~17세 + 18세 이상 | Play는 5세 이하, 6~8, 9~12, 13~15, 16~17, 18세 이상 중에서 고른다. "15세"에 딱 맞는 칸은 없다. B는 13~14세가 들어가는데, 개인정보 보호법상 만 14세 미만의 개인정보를 처리하려면 법정대리인 동의가 필요하고 AdMob이 광고 ID를 처리한다. 콘텐츠 등급의 "15세 이용가"는 아래 4번 설문 답으로 자동으로 정해지는 별개 항목이다 |
| Q2. 배포 국가 | **대한민국만** (권장) / 전 세계 | 게임 글이 한국어뿐이다. EEA·영국·스위스에 내면 AdMob 동의 창(UMP)을 넣어야 한다 |
| Q3. 콘텐츠 등급용 그림 확인 | 직접 보고 답 | ① 몬스터·이벤트 그림에 피가 보이는가 ② 몬스터 "서큐버스" 그림의 노출 정도 (옷을 입었는가, 성적인 자세인가) |

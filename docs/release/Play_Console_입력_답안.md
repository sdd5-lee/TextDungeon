## 7. AdMob 동의 창 만들기 (AdMob 승인이 난 뒤)

앱 코드는 동의 창을 띄우기만 한다. 창 내용은 AdMob에서 만들어 게시해야 뜬다. 게시하기 전에는 유럽에서도 창 없이 넘어가고, 그곳에서는 광고가 덜 나올 수 있다.

| AdMob 화면 | 넣을 것 |
| --- | --- |
| 개인정보 보호 및 메시지 → 유럽 규정(GDPR) → 메시지 만들기 | 앱: TextDungeon |
| 언어 | 영어 (필요하면 다른 언어 추가) |
| 개인정보처리방침 URL | `https://sdd5-lee.github.io/textdungeon-privacy/` |
| 사용자 선택 | 기본값 (동의, 관리) 그대로 |
| 게시 | 게시 |

- 앱의 옵션 화면에는 동의가 필요한 지역에서만 "광고 개인정보 설정" 버튼이 보인다. 한국에서는 보이지 않는다.

# 스토어 등록정보 (2026-10-30)

Play Console → 성장 → 스토어 등록정보 → 기본 스토어 등록정보에 그대로 붙여 넣는다. 숫자는 2026-10-30 코드와 데이터로 확인했다 (50층, 직업 9개, 몬스터 36종, 아이템 48개, 마법 14개, 신 5명, 난이도 3개).

## 앱 이름 (30자 이하)

```
TextDungeon
```

## 간단한 설명 (80자 이하)

```
글로 읽고 골라 내려가는 50층 던전 RPG. 휴대폰 안 AI가 다섯 신의 축복을 매번 새로 씁니다.
```

## 자세한 설명 (4000자 이하)

```
TextDungeon은 글로 진행하는 던전 탐험 RPG입니다.
층마다 벌어지는 일을 읽고 선택지를 골라, 50층 던전의 가장 깊은 곳까지 내려가세요.

■ 고르는 대로 달라지는 탐험
· 수상한 상인, 숨겨진 함정, 도박사의 제안, 치유의 샘
· 슬라임과 고블린부터 드래곤, 리치, 마왕까지 36종의 몬스터와 턴제 전투
· 장비와 소모품 48종, 마법서 14권
· 쉬움, 보통, 어려움 세 가지 난이도

■ 다섯 신의 축복
꿈속 천상에서 모험, 혼돈, 죽음, 투쟁, 보물의 신이 형상을 내밀며 축복을 건넵니다.
이 이야기는 휴대폰 안에서 돌아가는 AI가 그때그때 새로 씁니다. 글을 만들려고 서버에 보내지 않습니다.
혼돈의 주사위를 굴리면 무엇이 나올지 아무도 모릅니다.

■ 성장
· 전사, 마법사, 도적, 궁수로 시작하고 기사, 수도사, 성기사, 전투 마법사, 용사를 해금
· 직업마다 다른 고유 특성
· 모은 젬으로 영구 업그레이드와 특성 해금
· 도전과제와 도감

■ 알아 두세요
· 신들의 이벤트를 보려면 옵션에서 AI 모델(약 2.6GB)을 Wi-Fi로 받아야 합니다. 받지 않아도 게임은 할 수 있고, 이때 혼돈의 주사위는 미리 준비된 결과로 동작합니다.
· AI 기능은 기기 사양에 따라 느리거나 동작하지 않을 수 있습니다.
· AI가 쓴 글은 가끔 어색할 수 있습니다.
· 보상형 광고와 인앱 상품(광고 스킵, 젬 부스터)이 있습니다.
```

## 그래픽

| 항목 | 규격 | 파일 |
| --- | --- | --- |
| 앱 아이콘 | 512×512 PNG, 1MB 이하 | `docs/release/store/icon_512.png` |
| 그래픽 이미지 | 1024×500 PNG 또는 JPEG | `docs/release/store/feature_1024x500.png` |
| 휴대전화 스크린샷 | 2~8장, 긴 변이 짧은 변의 2배 이하 | `docs/release/store/screenshot_*.png` |

- 원본 그림 몇 장의 오른쪽 아래에 Gemini 별 표시가 있다. 아이콘과 그래픽 이미지에서는 그 부분을 잘라 냈다.
- 요즘 휴대폰 화면(20:9 등)은 2배를 넘는다. 스크린샷은 화면 전체를 1080×2160(2:1)에 줄여 넣고 양옆을 화면 가장자리 색으로 채웠다.
- 스크린샷 4장은 에뮬레이터에서 찍었다: 치유의 샘 이벤트, 거대 쥐 전투, 캐릭터 선택(마법사), 상점. 에뮬레이터에는 AI 모델이 없어 신들의 이벤트 화면은 없다. 실제 휴대폰에서 신들의 이벤트 화면을 찍어 더하면 좋다.
